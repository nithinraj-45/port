# Nithin Raj - Personal Portfolio Website

[Nithin Raj Portfolio]

A dark futuristic, recruiter-ready personal portfolio website for **Nithin Raj**, Computer Science Engineering student at Loyola-ICAM College of Engineering & Technology (LICET), Chennai.

---

## 🚀 Features

- **Dark Futuristic Aesthetic**: Built with a sleek `#080B11` backdrop, cyan/violet ambient lighting, glassmorphism panels, and smooth scroll reveal animations.
- **Floating 3D Levitating Profile Frame**: Highlights Nithin Raj's portrait in a 3D levitating card frame with neon glow lighting effects.
- **Verified Content**: Sourced strictly from Nithin Raj's official resume without exaggerated metrics or invented claims.
- **Interactive Capabilities Grid**: Categorized skills viewer for *Programming*, *Data*, *Creative*, and *Professional* skills.
- **Beyond Code Showcase**: Dedicated creative spotlight for Photography, Video Editing, Poster Design, Script Writing, and Social Media Promotion.
- **Single-Click Resume Download**: Direct PDF download button linked to Nithin Raj's verified resume (`Nithin_Raj_Resume.pdf`).
- **Recruiter CTA & Contact**: Interactive contact card with direct copy-to-clipboard for email (`nithinraj.28csb@licet.ac.in`), phone (`+91 7358024553`), location (`Chennai, India`), and message form.

## 🛠 Tech Stack

- **Frontend**: React 18, TypeScript, HTML5, Vanilla CSS / Tailwind CSS
- **Icons**: Lucide Icons
- **Fonts**: Google Fonts (*Outfit*, *Inter*)
- **Tooling**: Vite / Node.js HTTP Server

## 💻 Local Setup & Running

1. **Clone the repository**:
   ```bash
   git clone https://github.com/nithinraj-45/port.git
   cd port
   ```

2. **Run locally**:
   ```bash
   node server.cjs
   ```
   Open `http://localhost:3000` in your web browser.
